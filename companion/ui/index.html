What this app does and accesses
It only reads: the text log files the game writes in its Logs folder, the file names in your Screenshots folder (pictures are never opened), and where Tarkov is installed.
It never: touches the game's memory or process, injects anything, sends key presses or clicks, changes any game file, or uploads your data. The Tarkov Waypoint window inside this app talks to it on this PC only. It checks GitHub for updates.
